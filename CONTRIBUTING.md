# Contributing to Attome

Thank you for your interest.

## Code contributions are not accepted yet

Attome is in early development by a single team, and we are not accepting pull requests from outside
contributors at this time. Pull requests from outside the team will be closed without review. This keeps
the project's copyright in one place while its foundations are built; we will open contributions, with a
contributor agreement, once the project is ready for them.

## What is welcome now

- **Bug reports and ideas**: open an issue with what you expected, what happened and how to reproduce it.
- **Questions**: open an issue or a discussion.
- **Security problems**: never in a public issue; follow [`SECURITY.md`](SECURITY.md).

## Code of conduct

Everyone taking part in this project follows the [Code of Conduct](CODE_OF_CONDUCT.md).
