# الوثائق

وثائق Attome بالعربية. الصفحات التي لم تُترجم بعد تظهر بنصها الإنجليزي مع تنبيه في أعلاها.

- [البنية](architecture.md): طبقات النظام ومحركاته وأين يقع كل جزء.
- [الوكلاء](agents.md): ما يستطيع الوكلاء فعله، وأدواتهم، والتفويض، والضوابط.
- [التقويم الهجري](hijri.md): تواريخ أم القرى، والتصحيحات، والتجميع، والترقيم التلقائي، والعطل.
- [قواعد التكرار](duplicates.md): المقارنات، وما يحدث عند حفظ سجل مكرر، والمسح، والدمج والتراجع.
- [فرق الصفقات والتقسيم](deal-teams.md): أعضاء الفريق، وتقسيم الإيراد، والصفقات المكسوبة، والمغادرون.
- [المشتريات](procurement.md): طلبات الشراء، وأوامر الشراء، والاستلام، وفواتير الموردين، وفحص الميزانية.
- [الفوترة](invoicing.md): المسودات، والإصدار والترقيم، والإشعارات، ومستند الفاتورة، والكشوف، والأعمار، والشطب.
- [دوال لغة القواعد](rule-language.md): إصدارات اللغة والدوال التي يضيفها الإصدار الثاني.
- [طبقة البيانات](data-layer.md): المجمّعات، وفئات الاستعلامات، وإعادة المحاولة، والأقفال.
- [الاستعلامات البطيئة](slow-queries.md): تفعيل pg_stat_statements وauto_explain وقراءة الخطط.
- [النسخ الاحتياطي](backup.md)، [الإصدارات والدعم](versions-and-support.md)، [إصدارات الواجهة البرمجية](api-versions.md)، [خوادم النماذج](model-servers.md)
- [الإصدار](release.md)، [أهداف مستوى الخدمة](slo.md)، [الاختبار](testing.md)، [جهاز البناء](build-machine.md)

مرجع الواجهة البرمجية مولَّد من `openapi.json`، ويمكن الوصول إليه من رأس كل صفحة.

لبناء الموقع محليًا:

```sh
node scripts/docs-build.mjs
```
